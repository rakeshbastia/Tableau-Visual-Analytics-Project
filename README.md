# Tableau Visual Analytics Project

## Project Overview

This project demonstrates practical data visualization and analytical skills using Tableau Public. It covers fundamental Tableau concepts, data preparation, business analysis, calculated fields, parameters, and Level of Detail (LOD) expressions.

The project includes three business datasets: Retail, Healthcare, and Blinkit Orders.

## Objectives

- Understand Tableau and its applications in data analytics.
- Understand data cleaning and preparation using Tableau Prep.
- Analyse sales performance and profitability.
- Visualize healthcare treatment costs.
- Evaluate delivery performance.
- Perform dynamic Top N product analysis.
- Apply FIXED LOD expressions for city-level benchmarking.

## Datasets Used

| Dataset | Analysis |
|---|---|
| Retail Dataset | Sales, category performance, trends, and profitability |
| Healthcare Dataset | Treatment cost analysis and department rankings |
| Blinkit Orders Dataset | Delivery classification, Top N products, and city benchmarking |

## Assignment Details

### Q1–Q2: Tableau Fundamentals
- Introduction to Tableau and its advantages over spreadsheets.
- Tableau Prep and data cleaning concepts.
- Removing null values and duplicate records.
- Correcting data types.

### Q3–Q5: Retail Analysis
- Category Performance Analysis.
- Monthly Sales Trend Analysis.
- Profitability Investigation.

### Q6–Q7: Healthcare Analysis
- Heatmap: Treatment Cost by Department and Region.
- Bump Chart: Monthly Department Ranking based on Treatment Cost.

### Q8–Q10: Blinkit Orders Analysis
- Delivery Performance Classification using Calculated Fields.
- Dynamic Top N Products Analysis using Parameters.
- City-Level Benchmarking using FIXED LOD.
